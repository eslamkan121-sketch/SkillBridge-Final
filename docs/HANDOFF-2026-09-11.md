## 1. What this project is

**SkillBridge** is a full-stack career-transition platform: students build a profile (CV upload or self-report), get matched against real company roles / ESCO occupations, see skill-gap analysis, follow "learning paths" for each gap, take practice scenarios and mock-interview diagnostics, and run verified final assessments with webcam integrity. Employers and universities have dashboards. An AI Tutor (four personas) and an AI coach provide realistic conversational English interview practice with **ElevenLabs text-to-speech** voice output.

**Stack:**

- **Backend:** Python 3.12, FastAPI + uvicorn (served from `backend/`, absolute imports `app.*`, SQLite at `backend/skillbridge.db`, seeded into a live cohort of 9 students).
- **Frontend:** React + TypeScript + Vite (built to `frontend/dist`, served as static files by the backend on the same port).
- **Entrance:** `npm start` / `start.bat` at the repo root (`node scripts/start.mjs`; `--no-build` skips the frontend build). Backend runs with the repo `.venv` Python (`backend/.venv` — actually `.venv` at repo root per `scripts/lib.mjs` `path.join(ROOT, ...)`), i.e. `.venv/Scripts/python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000` from `backend/`.
- **Logging:** uvicorn access logs stream to the start.bat console / captured file.

**Boundaries that matter:** tests never read `.env` (keys are only picked up when shell-exported). `main._load_env()` reads the root `.env` with Python's default encoding on Windows (**cp1252** for the running interpreter) — so `.env` must stay pure ASCII. `backend/app/dotenv_local.py::load_root_env()` also loads the same `.env`.

## 5. Honest engineering assessment — problems and recommended fixes

1. **`.env` encoding fragility (real bug, will bite again).** `main._load_env()` reads the root `.env` with default-codepage `read_text()`. On the user's Windows box that's **cp1252**, so any non-ASCII character (a BOM, an em-dash, an accented name) in `.env` hard-crashes uvicorn at startup with `UnicodeDecodeError`. A single stray emoji or a copied-and-pasted key with a non-ASCII char will take the whole app down. **Fix:** read with explicit `encoding='utf-8-sig'` in `_load_env()` (and `dotenv_local`), or better, parse `.env` bytes and skip-comment robustly — one place, bug-proof. Alternatively strip/reject non-ASCII with a loud warning instead of silent crash.
2. **Multi-interpreter / ad-hoc server sprawl.** During this session three stray backends appeared (8001/8002/8003) from a mix of `Start-Process` and `start.bat` attempts; I had to hunt and kill them by port. Only `start.bat` should ever be used. Suggest: a single "how to run" is already in AGENTS.md, but consider a health/pid check in `start.mjs` that stops *other* SkillBridge uvicorns on this machine before binding (like it already checks port-in-use then *fails over* — failing over silently to 8001++ is arguably worse; a stale 8000 starter should be stopped or block with a clear message, not spawn 8003).
3. **Secrets in private `.env` vs. test-bootstrapping split brain.** The design (tests never read `.env`) is good, but it means two config systems (shell-export vs `.env`) diverge. Keep it simple: keep the guard, but document in `docs/job-providers.md` exactly which knobs are read *only* via shell export (live market test) vs `.env` (app runtime).
4. **JSearch's monthly 429 is a product risk.** The feed visibly depends on one paid provider whenever the user is not in a free tier. The keyless provider set is now a genuine fallback, but consider an honest banner ("JSearch monthly limit reached") in the Dashboard rather than the current "12 configured" phrasing, which over-promises an online state.
5. **`skillbridge.tts` startup log never prints** (root logger at WARNING, no handler) — for ops sanity and for future agents, add a minimal logging config in `main.py` at import (INFO for `skillbridge.*` + uvicorn), or lower the root level. Small, high-value.
6. **VEX voice gap is a config/support problem, not code**: the personas table will show three working and one 404 until the account has a real Vex voice. Recommend making VEX fall back to a working voice (e.g. Daniel `onwK4e9ZLuTAKqWW03F9` or Matilda for a female Vex) if no dedicated VEX voice exists — and surface `voice_not_found` as a distinct, green-able status in `tutor_voice_status()` (today it only reports loaded-not-loaded, hides the *actually-broken* case).
7. **Docs drift.** AGENTS.md is superb but the *latest* jobs provider count moved to 12; some older sections still say "10 providers" / "8 providers". When the next agent touches jobs, sweep those numbers. Also `docs/job-providers.md` should state the live `12 configured = X online` reality after LinkedIn/Google are added.
