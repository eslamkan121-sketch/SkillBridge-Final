## Architecture and authority boundaries

The active learning flow is:

`Diagnostic → Personalized Path → Lesson → static/AI Practice review → Mini Check → topic completion`

- A diagnostic is topic-scored deterministically from its persisted competency-tagged questions.
- A path belongs to one completed diagnostic via `personalized_paths.diagnostic_id`; a newer completed diagnostic makes an older path stale.
- Practice is informational and does not complete a topic; a Mini Check pass persists topic completion.
- Static Python review uses AST/structure checks only. It **never executes learner code**.
- Learning, Practice, and Mini Check never create Verified Skills. Only the official Final Assessment retains Verified Skill authority.
